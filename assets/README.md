# Asset Placeholder Guide

Semua file di folder ini adalah placeholder original untuk membantu layout dan prototyping. Mereka bukan artwork resmi dan tidak dimaksudkan sebagai pengganti final.

## Penggantian yang disarankan

- `brand/`: ganti mark dan wordmark dengan identitas brand milik proyek.
- `markers/`: pertahankan siluet/status yang mudah dibedakan; sesuaikan bentuk dengan sistem ikon final.
- `placeholders/`: ganti dengan foto/ilustrasi/video poster yang memiliki izin.
- `downloads/`: ganti dengan wallpaper, sticker, dan emoji final dalam ukuran responsif.

## Checklist sebelum production

- Pastikan lisensi dan pemilik setiap file terdokumentasi.
- Sediakan alt text, caption, dan versi high-contrast bila diperlukan.
- Kompres raster ke WebP/AVIF; pertahankan SVG untuk icon/marker.
- Jangan menghapus label `placeholder` dari file sebelum konten final tersedia.
